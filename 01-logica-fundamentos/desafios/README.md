# Desafios de Lógica de Programação e Depuração

Coleção de desafios de depuração em C. Cada um deles contém **erros sutis de lógica de execução** que passam pelo compilador sem gerar erros de sintaxe (ou seja, o código compila), mas produzem comportamentos inesperados, travamentos (*crash*) ou resultados matemáticos incorretos em tempo de execução.
